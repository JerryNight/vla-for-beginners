# 零硬件游乐场

**这一章是选修课。** 建议把全书读完再来看。

这里列的都是「不需要买机器人」就能接触 VLA 的路径，按需要的设备从少到多排。每条都注明「能学到什么」——因为跑通本身没有价值，理解才有。

---

## 第一层：什么都不装（浏览器 / 看视频）

| 项目 | 做什么 | 能学到什么 |
|---|---|---|
| **OpenVLA 的在线 demo** | 上传一张图，输入指令，看模型输出动作 | 感受「输入图和话、输出 7 个数」是什么体感 |
| **LeRobot 的演示视频** | 看遥操作采集、训练、推理的完整流程 | 建立「一条数据从哪来」的直观印象 |
| **LIBERO / CALVIN 的论文视频** | 看基准测试里机器人怎么失败 | 建立「成功率 80% 长什么样」的直觉 |

**这一层的价值被低估了。** 很多人一上来就装环境，结果陷在依赖地狱里，反而没时间理解概念。

先看，再装。

---

## 第二层：普通笔记本（无独显也能跑）

| 项目 | 需要什么 | 能学到什么 |
|---|---|---|
| **MuJoCo** | Python，几百 MB | 物理仿真的基本概念：关节、力矩、接触 |
| **Diffusion Policy 的 PushT demo** | 一张普通显卡或 CPU（慢但能跑） | 扩散策略到底在干什么，亲眼看到「多峰」 |
| **LeRobot + SmolVLA** | 8GB 内存，可选 GPU | 一个完整但很小的 VLA 从加载到推理的全过程 |

**PushT 值得单独说。** 它是 Diffusion Policy 论文里的经典任务：把 T 形块推到目标位置。

它的好处是：

- 训练数据小（几百条），能在一张消费级卡上几小时训完；
- 任务简单，成功失败一眼看得出；
- **能看到多峰现象**——模型会学到「从左推」和「从右推」两种策略。

这是把[第 3.3 节](../part2-connecting/09-action-head.md)的抽象概念变成直觉的最快方式。

## 第三层：有一张 8–24 GB 的 GPU

| 项目 | 大致门槛 | 能学到什么 |
|---|---|---|
| **微调 OpenVLA（LoRA）** | 16GB+ 显存 | 后训练到底在改什么，LoRA 的效果边界在哪 |
| **在 LIBERO 上跑评估** | 12GB+ | 基准测试怎么跑，成功率怎么算 |
| **自己训一个小的 diffusion policy** | 8GB+ | 完整走一遍「数据 → 训练 → 评测」 |

**关于微调 OpenVLA**：社区里有不少 LoRA 微调的脚本，通常能在单张 4090 上跑起来。

但要提醒一句：**微调出来的模型大概率不如原版好用**。因为你的数据量远小于它的训练集，很容易过拟合。

**这个过程的价值不在结果，在于你会亲眼看到**：

- 学习率稍微大一点，损失就炸；
- 数据少了，模型立刻开始背答案；
- 动作归一化参数没对齐，输出幅度就全乱。

这些是书上看一百遍也记不住的。

## 第四层：愿意装仿真环境

| 环境 | 特点 | 适合 |
|---|---|---|
| **LIBERO** | 130 个任务，4 个套件，VLA 论文最常用 | 想复现论文数字 |
| **CALVIN** | 长程、连续指令 | 研究长任务 |
| **SimplerEnv** | 刻意对齐真机 | 想让仿真结果可信 |
| **Isaac Lab** | NVIDIA 生态，GPU 加速，速度快 | 大规模并行训练 |
| **MetaWorld / RoboSuite** | 轻量，任务简单 | 快速验证想法 |

**装之前先想清楚你要干什么。**

如果你只是想「体验一下」，第二层就够了。

如果你想复现某篇论文的数字，用它用的那个基准，别换。

如果你想训练自己的策略，选一个任务简单、渲染快、社区活跃的——Isaac Lab 在这三点上都最好，但它的学习曲线也最陡。

---

## 一个提醒：不要陷在环境里

这是新手最常见的时间黑洞：

```text
装 CUDA → 版本冲突 → 重装驱动 → 又冲突 → 换 conda → 还是不行 → 三天过去了
```

**如果你三天还没跑通第一个 demo，停下来。**

换一条路：
- 用 Docker 镜像（社区通常有人做好）；
- 用 Colab（有免费 GPU，环境是配好的）；
- 或者干脆回到第一层，先看视频。

**跑通环境不是学习，是运维。** 它对理解 VLA 的贡献接近于零。

---

## 一条推荐的动手路线

如果你确实想动手，按这个顺序，每一步都有明确的收获：

1. **看 OpenVLA 的在线 demo**（30 分钟）
   → 建立「输入输出长什么样」的直觉

2. **跑通 PushT 的 diffusion policy**（半天到一天）
   → 看到多峰，理解为什么不能直接回归

3. **在 LeRobot 上加载 SmolVLA，喂一张自己的图**（半天）
   → 理解「图像 token + 语言 token → 动作」的完整通路

4. **在 LIBERO 上跑一次评估**（一天）
   → 理解成功率是怎么算出来的，以及为什么这个数字不可全信

5. **（可选）LoRA 微调 OpenVLA**（两三天）
   → 理解后训练，以及它有多容易过拟合

**到第 4 步，你对 VLA 的理解就已经超过大部分「看过论文」的人了。**

因为你知道数字是怎么来的。
