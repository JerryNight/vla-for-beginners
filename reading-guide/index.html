    怎么读这本书¶

    这本书的假设¶

    假设你：

    • 知道「模型」「训练」这类词大概是干什么用的，但说不清细节；
    • 没写过深度学习代码，或者写过但没碰过机器人；
    • 想搞清楚 VLA 是怎么回事，但不想先花两周补课。

    如果连第一条都不成立，直接去 2.0 章，那章是专门为你写的。

    三条推荐路线¶

    不同的人该读不同的部分。先对号入座。

    按顺序读完全书。不要跳章，第 2 部分和第 3 部分是有依赖的—— 第 3 部分讲融合时，会反复用到第 2 部分讲过的「向量」和「注意力」。

    中途如果卡在某个类比上，直接跳到下一节，不要在单点上死磕。 这本书的设计是：同一个概念会在不同章节用不同角度出现三次， 第一次没懂，第三次往往就通了。

    跳过 2.0、2.2、3.1，从这几节开始：

    1. 2.3 动作——机器人侧最陌生的部分
    2. 3.3 动作解码——和 NLP 的生成范式对照着看
    3. 4.2 行为克隆——监督学习在这里会遇到什么新麻烦
    4. 第五部分全部——谱系地图

    只读四节：1.1、 1.3、 2.3、 5.1。

    读完你会有能力参与一场关于 VLA 的对话，不至于说外行话。

    书里的几种标记¶

    「注意」块

    用来提示一个容易搞混的点，或者一个常见错误。跳过不影响主线，但读了能少踩坑。

    用来解释抽象概念的生活类比。这本书里几乎所有难概念都有一个类比先行。 如果某个类比你觉得不贴切，欢迎提 Issue——那说明我选错了参照物。

    自测三问

    每章末尾都有。三问都答得上来，说明这章真懂了；有一问答不上来，回去重读对应小节。 不要跳过这三问——能复述不等于能理解，回答问题才会暴露漏洞。

    每章最后的一句话总结。如果时间紧，只读这些加粗的句子也能拼出完整框架。

    关于术语¶

    这个领域的术语混乱程度堪称灾难。同一个东西可能有四五个名字：

    你可能会看到 其实是同一个东西
    策略 / policy / π 输入观测、输出动作的那个函数
    示教 / demonstration / 轨迹 / trajectory / episode 一段「人怎么做这件事」的录像加动作记录
    动作头 / action head / action expert / decoder 把特征变成动作数字的那一小块网络
    本体 / embodiment / platform 具体那台机器人的身体结构
    后训练 / fine-tuning / 微调 在大模型基础上用少量专门数据再训一轮

    全书第一次出现时会给中英文对照。完整的对照表在附录。

    一个提醒¶

    这个领域变化极快。书里提到的具体模型、参数量、性能数字，半年后就可能过时。

    所以我刻意把重点放在不会变的东西上：为什么需要语言接口、为什么动作是连续量、为什么模仿学习会分布漂移、为什么推理频率是个硬约束。这些是结构性的问题，换十代模型也还在。

    读的时候请把具体模型名当成「例子」，而不是「结论」。
